# How it works

Every time the user inputs a number the number gets sorted with all the ones inputted before it in an array using for and while loops.

# How'd we come up with it

We thought that if sorting began at every step it, would streamline the sorting to only change one item per run.

# Efficiency

Compared to the old sort, this sort is a little bit more optimized. The old sort would have to alternate every time item i was greater than i+1.

# Pros/Cons

It's still primitive and uses the same system built in the previous build. However, a pro is that it's able to take care of each number one at a time.
